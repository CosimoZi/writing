# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Repository Overview

This is an **Obsidian vault** for creative writing, not a software project. It contains a literary work titled《窃国游戏》(roughly "The Game of Stealing a Nation") — a multi-act narrative set in historical France, written in Chinese.

## Structure

- `窃国游戏/` — the main work, organized by acts (幕) with numbered files:
  - `0. 序幕` — Prologue
  - `1. 第一幕` — Act One (written as scenes/episodes with stage directions)
  - `3. 第三幕` — Act Three
  - `演出说明.md` — Production/performance notes (currently empty)
  - `灵感碎片.md` — Inspiration fragments, quotes, and loose ideas
- `.obsidian/` — Obsidian configuration (do not edit manually)

## Version Control

The vault uses the **obsidian-git** plugin for automatic backups. Commits are auto-generated with the message format `vault backup: YYYY-MM-DD HH:mm:ss`. Auto-backup triggers after file changes at 1-minute intervals.

## Working with This Vault

- The writing mixes prose, dramatic script formatting (stage directions in `_【】_`), and literary Chinese.
- `灵感碎片.md` collects unstructured notes, literary references (Baudelaire, Lewis Carroll, Proust, biblical passages), and character ideas — treat it as a living scratchpad.
- The work incorporates Latin legal terminology (from the protagonist's notary background) and multilingual elements (French, Italian, English, Latin).
- When assisting with this project, respond in Chinese unless asked otherwise.
